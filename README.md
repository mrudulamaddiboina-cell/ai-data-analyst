# 🤖 AI Data Analyst

An AI-powered data analysis platform that allows users to upload datasets, ask questions in natural language, generate visualizations, and discover meaningful insights.

## ✨ Features

- 📂 Upload and analyze datasets
- 💬 Ask questions about data
- 📊 Generate data visualizations
- 🔍 Discover useful patterns and insights
- 🧪 Automated testing
- ⚙️ GitHub Actions CI workflow

## 🛠️ Technologies Used

- Python
- Pandas
- FastAPI
- Pytest
- HTTPX
- GitHub Actions
